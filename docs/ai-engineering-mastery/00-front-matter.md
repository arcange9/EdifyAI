# AI ENGINEERING MASTERY

## A 90-Day Practical Journey from Python to Machine Learning, Deep Learning, LLMs, RAG, AI Agents, and Production AI

---

### Target Audience
A motivated secondary-school student or beginner developer with basic programming knowledge, access to a normal laptop, and a desire to become an AI Engineer in 3 months.

### Book Philosophy
This book teaches you to *think like an AI Engineer* — not just call APIs. You will understand how AI systems work internally, build them yourself, and deploy them to production. Every concept is taught with words + code + mathematics + diagrams + projects.

### Difficulty Progression
```
BEGINNER → FOUNDATION → INTERMEDIATE → ADVANCED → PRODUCTION AI ENGINEERING
```

### Technology Stack (All Free or Open-Source)
Python 3.11+, Jupyter Notebook, VS Code, Git, GitHub, NumPy, Pandas, Matplotlib, Scikit-learn, PyTorch, Hugging Face Transformers, FastAPI, Docker, SQLite, ChromaDB, Ollama, REST APIs
