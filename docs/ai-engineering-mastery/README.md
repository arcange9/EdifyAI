# AI Engineering Mastery: A 90-Day Practical Journey

A comprehensive, beginner-friendly textbook that takes you from zero to building production AI applications in 90 days.

## What's Inside

**43 chapters + 3 appendices across three monthly phases:**

### Month 1 — Foundations (Days 1-30)
Python, NumPy, Pandas, Matplotlib, Linear Algebra, Probability & Statistics, Calculus & Optimization, Data Preprocessing, Machine Learning (Regression, Classification, Decision Trees), Model Evaluation

### Month 2 — Deep Learning & Modern AI (Days 31-60)
Neural Networks, Backpropagation, PyTorch, CNNs, RNNs/LSTMs, Transformers, Tokenization & Embeddings, LLMs & GPT, Prompt Engineering, Hugging Face, Fine-tuning (LoRA), Quantization, GPU Hardware

### Month 3 — AI Engineering & Production (Days 61-90)
LLM Application Architecture, AI APIs, Structured Outputs, Vector Databases, RAG (Basic + Advanced), AI Agents, Multi-Agent Systems, AI Safety & Guardrails, FastAPI, Docker & Deployment, Monitoring & Cost Optimization, Production Architecture, Career Skills, Capstone Project

## How to Use This Book

1. Start with `00-front-matter.md` for the introduction and reading guide
2. Follow the schedule in `month1/00-90-day-schedule.md`
3. Read one chapter per 2-day block
4. Complete the projects at the end of each chapter
5. Take the final assessment in `appendix-c-final-assessment.md`

## Who It's For

- Beginners with no AI background
- Students who know basic Python
- Developers transitioning to AI engineering
- Anyone who wants to understand and build AI applications

## Tools Used

All tools are free and open-source: Python, PyTorch, Hugging Face, FastAPI, SQLite, ChromaDB, Docker, Ollama
